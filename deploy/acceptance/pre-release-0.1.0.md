# Face Serve 0.1.0 发布前验收记录

日期：2026-09-24

状态：有条件通过。ONNX CPU 构建已通过本机自动化验收；公开发布模型包前仍需完成许可证确认和目标机验收。

## 本次发布范围

- systemd 主服务、就绪检查定时器、失败重启限制和安全加固；
- `facectl` 生命周期、依赖服务白名单、诊断、备份、版本查看和回滚；
- 离线依赖收集、打包、校验、安装、升级失败回滚和卸载；
- ONNX CPU、ONNX CUDA 与 RK3588/RKNN 配置模板；
- 模型、运行时、设备、目录和依赖预检；
- `/healthz` 存活检查及 `/readyz` HTTP 503 就绪语义；
- SPDX 2.3 SBOM 和第三方许可证清单。

## 已通过项目

- 隔离发布分支完整测试：28 项通过；
- Shell 脚本语法检查；
- Python 部署辅助程序编译检查；
- Git 差异格式检查；
- systemd unit 语法检查；
- ONNX CPU 离线 wheel 安装和关键运行库导入；
- ONNX 模型与目录预检；
- 真实 ONNX 服务启动以及 `/healthz`、`/readyz` 检查；
- 发布包外层 SHA-256 与内部逐文件 SHA-256 校验；
- SBOM 和第三方许可证清单生成。

## 发布前仍需完成

1. 在全新、断网且可丢弃的 Linux x86_64 目标机上，以 root 执行安装、重启、升级和回滚验收。
2. 在 RK3588 aarch64 目标机上验证 RKNN wheel、NPU 推理、服务重启和回滚。
3. 在匹配的 NVIDIA 驱动/CUDA 目标机上验证 ONNX CUDA 专用依赖锁和启动流程。
4. 确认随离线包分发的所有人脸模型具有公开再分发许可。
5. 如正式发布策略要求签名，使用外部管理的发布密钥完成签名。

在上述目标机和许可证门禁关闭前，可以推送源码准备分支，但不得创建公开模型包 Release 或正式版本标签。
